# Future Interns – Data Science & Analytics Task 3

## College Event Feedback Analysis

This project analyzes student feedback from college events using data science and basic Natural Language Processing (NLP).

### Project Objectives

- Clean and prepare student feedback data
- Analyze student ratings on a 1–5 scale
- Perform sentiment analysis on written feedback
- Visualize satisfaction trends using charts
- Identify common feedback themes
- Provide recommendations for future college events

### Tools & Technologies

- Python
- Google Colab
- Pandas
- Matplotlib
- Seaborn
- TextBlob
- WordCloud

### Dataset

The project uses a simulated student feedback dataset containing responses from students about different college events.

The dataset includes:
- Student ID
- Event
- Department
- Year
- Rating
- Feedback Comment

### Analysis Performed

1. Data cleaning and preparation
2. Rating distribution analysis
3. Average rating by event
4. Sentiment analysis
5. Rating vs sentiment analysis
6. Department-wise analysis
7. Keyword analysis
8. Word cloud visualization

### Key Recommendations

- Improve event registration and scheduling
- Increase interactive and hands-on activities
- Improve seating, sound, lighting and equipment facilities
- Manage crowd size effectively
- Collect consistent feedback after every event
- Track feedback results across future events

### Project Files

- `Future_Interns_Task_3_College_Event_Feedback_Analysis.ipynb` – Jupyter/Google Colab notebook
- `student_event_feedback.csv` – Dataset
- `Future_Interns_Task_3_Mini_Report.pdf` – Mini project report
- `event_analysis_summary.csv` – Analysis summary

### Conclusion

This project demonstrates how data science and NLP can be used to analyze student feedback and generate useful insights for improving college events.
